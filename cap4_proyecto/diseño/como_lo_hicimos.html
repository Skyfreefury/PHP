1. Qué es Arrivederci

Arrivederci es la web de una pizzería. Un cliente registrado entra con su correo y su clave, mira la carta, mete productos en el carrito y hace el pedido. El pedido se guarda en la base de datos como «no enviado», listo para que la cocina lo prepare.

3. Los pasos que seguimos

1

Analizar y escribir el ERS

Antes de programar, se escribió qué debe hacer la web: 15 requisitos funcionales (RF), 6 no funcionales (RNF), 3 casos de uso y 5 reglas de negocio. Por ejemplo, RF-05 dice «agregar productos al carrito» y RN-01 dice «de 1 a 10 unidades».

2

Diseñar la base de datos

Del análisis salen 5 tablas: categoria, producto, cliente, pedido y pedido_producto. La última une cada pedido con sus productos y guarda el precio del momento, así un pedido antiguo no cambia si sube un precio.

3

Dibujar los prototipos

En Figma se dibujaron el login, la lista de productos, el carrito y la confirmación. Con eso claro, el HTML y el CSS se escriben sin dudar dónde va cada cosa.

4

Conectar con la base de datos

La clase BD abre una sola conexión PDO por petición y la reutiliza. Todas las consultas usan prepare con parámetros, para que nadie pueda colar SQL desde un formulario.

5

Login y sesión

login.php llama a Cliente::comprobar(), que busca el cliente por correo y comprueba la clave con password_verify, porque en la base la clave está cifrada. Si es correcta, guarda los datos en la sesión. La clase Sesion se llama al principio de cada página privada: si nadie ha entrado o han pasado 15 minutos, manda al login.

6

Catálogo

categorias.php pinta las 3 categorías con Categoria::todas(). Al pulsar una, productos.php muestra sus 8 productos con Producto::porCategoria(). Todo texto de la base sale con htmlspecialchars para evitar código inyectado.

7

Carrito

El carrito vive en la sesión como una lista id del producto → unidades. La clase Carrito tiene 3 métodos: agregar suma unidades con un tope de 10, cambiar pone una cantidad nueva y eliminar quita la línea. carrito.php calcula subtotales y total.

8

Pedido con transacción

Pedido::crear() guarda la cabecera del pedido y todas sus líneas dentro de una transacción. Si falla una sola línea, se deshace todo con rollBack y no queda un pedido a medias. Después se vacía el carrito y se muestra la confirmación con el número de pedido.

9

Historial

historial.php lista los pedidos del cliente con fecha, artículos, total y estado. El total se calcula en SQL con SUM(Unidades * Precio).

10

Diseño y pruebas

Una sola hoja css/estilos.css da estilo a todas las páginas y las adapta al móvil. Al final se pasaron las 5 pruebas de aceptación del ERS.

4. Cómo están organizados los archivos

cap4_proyecto/
├── index.php              portada pública
├── login.php              formulario de entrada
├── logout.php             cierra la sesión
├── categorias.php         las 3 categorías
├── productos.php          productos de una categoría
├── agregar-carrito.php    recibe el formulario "Agregar al carrito"
├── carrito.php            ver el carrito
├── actualizar-carrito.php cambiar unidades o eliminar una línea
├── realizar-pedido.php    guarda el pedido
├── confirmacion.php       "¡Pedido recibido!"
├── historial.php          mis pedidos
├── clases/                BD, Cliente, Sesion, Categoria, Producto, Carrito, Pedido
├── css/estilos.css        todo el diseño
├── img/                   fotos de productos y categorías
├── bd/arrivederci.sql     crea la base y mete los datos
└── memoria/               ERS, esquemas y prototipos
Las páginas que muestran algo (carrito.php, productos.php…) están separadas de las que solo hacen algo y redirigen (agregar-carrito.php, realizar-pedido.php…). Así, recargar la página nunca repite un pedido.

5. Recorrido por la web

6. Cómo ponerlo en marcha

  1. Arrancar MySQL desde el panel de XAMPP.
  2. Importar bd/arrivederci.sql en phpMyAdmin (pestaña Importar). Crea la base, las tablas, los 24 productos y el cliente de prueba.
  3. Revisar clases/BD.php. Está preparado para MySQL en el puerto 3307 con usuario root y clave root. Si tu MySQL usa otro puerto o clave, se cambia en esas 3 constantes.
  4. Abrir una terminal en la carpeta que contiene cap4_proyecto y arrancar el servidor de PHP:
php -S localhost:8001 -t cap4_proyecto
  1. Abrir en el navegador http://localhost:8001 y entrar con cliente@pizzeria.es / 1234.
También funciona con Apache de XAMPP: se copia la carpeta cap4_proyecto dentro de htdocs y se abre http://localhost/cap4_proyecto/.
